# WozterDev downloads

Download the latest prebuilt WozterDev application. This public repository distributes application packages; it does not contain the WozterDev application source code.

## Latest: 1.4.0

- **Windows x64 installer:** [WozterDevSetup.msi](https://github.com/WozterDev/wozterdev-downloads/releases/latest/download/WozterDevSetup.msi)
- **Linux x64:** [tar.gz](https://github.com/WozterDev/wozterdev-downloads/releases/latest/download/WozterDev-1.4.0-linux-x64.tar.gz)
- **Linux ARM64:** [tar.gz](https://github.com/WozterDev/wozterdev-downloads/releases/latest/download/WozterDev-1.4.0-linux-arm64.tar.gz)
- **Checksums:** [SHA256SUMS.txt](https://github.com/WozterDev/wozterdev-downloads/releases/latest/download/SHA256SUMS.txt)

To install on Windows, download and run the MSI. To run on Linux, download the archive for your architecture, extract it, and run the `WozterDev` executable. Linux users install PHP, Node.js/npm, Python, Java, or Go separately when needed by their projects.

This release provides Windows and Linux packages. macOS packages are skipped for now. GitHub automatically shows source-archive links for release tags and does not allow those links to be hidden. Tags in this downloads repository point to empty snapshots, so their generated ZIP and gzip source archives contain no files and no WozterDev application source code. Install using the attached platform packages above.
