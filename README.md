# WozterDev downloads

Download the latest prebuilt WozterDev application. This public repository distributes application packages; it does not contain the WozterDev application source code.

## Latest: 1.2.1

- **Windows x64 installer:** [WozterDevSetup.msi](https://github.com/WozterDev/wozterdev-downloads/releases/latest/download/WozterDevSetup.msi)
- **Linux x64:** [tar.gz](https://github.com/WozterDev/wozterdev-downloads/releases/latest/download/WozterDev-1.2.1-linux-x64.tar.gz)
- **Linux ARM64:** [tar.gz](https://github.com/WozterDev/wozterdev-downloads/releases/latest/download/WozterDev-1.2.1-linux-arm64.tar.gz)
- **macOS Intel:** [ZIP app bundle](https://github.com/WozterDev/wozterdev-downloads/releases/latest/download/WozterDev-1.2.1-osx-x64.zip)
- **macOS Apple Silicon:** [ZIP app bundle](https://github.com/WozterDev/wozterdev-downloads/releases/latest/download/WozterDev-1.2.1-osx-arm64.zip)
- **Checksums:** [SHA256SUMS.txt](https://github.com/WozterDev/wozterdev-downloads/releases/latest/download/SHA256SUMS.txt)

See the [release notes](https://github.com/WozterDev/wozterdev-downloads/releases/latest) for changes and installation requirements. The macOS app is unsigned and may require approval in Privacy & Security on first launch. Linux and macOS users install PHP, Node.js/npm, and Python separately if they need those project runtimes.

GitHub automatically shows source-archive links for release tags and does not allow those links to be hidden. The `v1.0.5`, `v1.2.0`, and `v1.2.1` tags in this downloads repository point to empty snapshots, so their generated source archives contain no files and no WozterDev application source code. Install using the attached platform packages above.
